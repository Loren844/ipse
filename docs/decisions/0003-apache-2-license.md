# 0003 — Apache License 2.0

- **Status:** Accepted
- **Date:** 2026-11-12

## Context

The project wants contributors, especially connector authors, and as little friction as possible for them. The alternative considered was the AGPL, which prevents closed online versions but deters some contributors and companies.

## Decision

Ipse is licensed under the **Apache License 2.0**.

## Consequences

- Anyone can use, modify and redistribute Ipse, including in closed products.
- The license includes an explicit patent grant, which MIT does not.
- Dependencies must be compatible: no GPL or AGPL crates.
- Changing license later requires the agreement of every contributor, so the choice is effectively final once outside contributions are accepted.
